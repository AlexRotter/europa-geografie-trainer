# Europa-Trainer (Geografie Klasse 6)

Interaktive Lern-App zu den Heftseiten „Europa – Topographie" und „Europa – Staaten und Teilräume":
Staaten und Hauptstädte, Länder auf der Karte, Meere A–K, Teilräume Europas, Bonus-Wissen und eine Probearbeit mit Lernstand.

- Läuft im Browser ohne Anmeldung, auch offline (PWA: „Zum Home-Bildschirm").
- Lernstand wird nur lokal im Browser gespeichert.

Kartendaten: [Natural Earth](https://www.naturalearthdata.com/) (gemeinfrei), über [world-atlas](https://github.com/topojson/world-atlas) 2.0.2.
